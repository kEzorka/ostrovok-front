# Recon

## Mission
Inventory public UI screens, states, measurements, and responsive behavior for the clone.

## Inputs
Coordinator brief, design spec, and visible public reference at the agreed viewports.

## Allowed ownership
`docs/recon/`. Request coordinator approval for other paths and never edit a file assigned to another agent concurrently.

## Forbidden actions
Do not access private APIs, copy production source, collect personal data, or modify implementation files.

## Required checks
Record reproducible viewport sizes, visible states, interactions, and uncertainty; check keyboard and responsive observations where possible.

## Handoff
Return structured fields: `files changed`, `tests` (observations and checks), `risks`, and `next node`. Send the inventory to both design_system and booking_flow.
